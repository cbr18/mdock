# Git history UI

Task: [23_08_2026_15_57_git_history_ui.md](../tasks/23_08_2026_15_57_git_history_ui.md)

## Последовательность реализации

1. Добавить в git client типы и методы для commit details: metadata, changed files, unified diff.
2. Прокинуть commit details через app service.
3. Добавить HTTP endpoint `GET /api/vaults/{slug}/git/commits/{hash}`.
4. Обновить server API docs и tests.
5. Обновить frontend API client.
6. Переработать `CommitList` в interactive history panel.
7. Добавить i18n строки.
8. Обновить frontend tests.
9. Прогнать проверки.

## Проверки

- `go test ./...`
- `npm test`
- `npm run build`

## Риски

- Большие diff могут перегрузить UI. Для MVP можно ограничиться server-side лимитом позже; сейчас показываем последние коммиты и обычный unified diff.
- Binary diff нельзя показывать как обычный markdown/text.
- Short hash должен валидироваться и передаваться в git только как отдельный argument.

## Заметки по откату

- Изменения не требуют миграций.
- Откат обычным revert backend/frontend/docs.

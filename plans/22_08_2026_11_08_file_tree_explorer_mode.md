# File tree explorer mode

Task: [22_08_2026_11_08_file_tree_explorer_mode.md](../tasks/22_08_2026_11_08_file_tree_explorer_mode.md)

## Последовательность реализации

1. Перевести состояние панели файлов с одного массива `entries` на map `directory path -> entries`.
2. Добавить состояние раскрытых папок и сохранение в `localStorage`.
3. Добавить lazy-load папок при раскрытии.
4. Заменить render списка на рекурсивное дерево с отступами.
5. Обновить create/delete, чтобы перезагружалась затронутая папка.
6. Обновить стили для tree rows, disclosure-кнопки и вложенных уровней.
7. Обновить i18n при необходимости.
8. Расширить frontend-тесты на раскрытие папки и вложенный файл.
9. Прогнать проверки и smoke.

## Проверки

- `npm test`
- `npm run build`
- `go test ./...`
- `cd test && docker compose up -d --build`
- `./test/run-smoke.sh`
- Playwright MCP ручная проверка раскрытия папки, create/delete и открытия файла.

## Риски

- Можно случайно сломать текущий edit flow, если удаление выбранного файла не очищает состояние редактора.
- При смене языка нужно пересортировать или перезагрузить entries.
- При stale `localStorage` раскрытая папка может отсутствовать, это должно обрабатываться без ошибок.

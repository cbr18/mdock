# Admin and user management API

Status: DONE
Created: 2026-08-14 19:13

## Проблема

Есть bootstrap/register/login, но нет управляемого server-side user lifecycle: смена пароля, rename login, disable/delete user, reset sessions.

## Доказательства

- API содержит только auth/register/login/me/logout.
- Пользователи хранятся в SQLite, но нет admin endpoints.

## Нефункциональные ограничения

- Не раскрывать password hashes.
- Нужна role/admin модель перед опасными операциями.
- Rate limiting/security hardening должны быть учтены.

## Не входит в задачу

- UI.
- LDAP/OIDC.
- App-passwords.

## Желаемое поведение

- Admin может управлять пользователями через API.
- Пользователь может сменить свой пароль.
- Sessions можно отзывать.

## Затронутые области

- `store`
- `app`
- `httpapi`
- auth/security docs

## Заметки по реализации

- Добавлены `users.is_admin` и `users.disabled` с совместимым `ALTER TABLE` для существующей SQLite DB.
- Bootstrap-пользователь всегда становится admin и включается обратно, чтобы не потерять административный доступ.
- Смена своего пароля, админский сброс пароля и disable пользователя инвалидируют существующие сессии пользователя.
- Admin API не возвращает password hashes.

## Критерии приёмки

- Admin endpoints защищены.
- Password change инвалидирует существующие сессии пользователя.
- Tests проходят.

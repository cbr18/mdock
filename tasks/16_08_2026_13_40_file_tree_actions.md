## Проблема

На странице хранилища панель файлов нельзя свернуть, а файлы/папки нельзя создавать или удалять из UI. Также заголовок "Редактор" рядом со значком папки вводит в заблуждение, потому что область содержит и просмотрщик.

## Доказательства

- Пользователь указал: "как минимум в редакторе надо убрать надпись \"Редактор\" где значок папки - там же еще просмотрщик".
- Пользователь указал: "панель слева надо иметь возможность свернуть".
- Пользователь указал: "возможность создать и удалить файл и папку. прям на папке должны быть справа кнопик кдалить и добавить (файл/подпапку). на файле просто добавить".

## Нефункциональные ограничения

- Использовать существующий JSON file API.
- Не менять backend contract.
- Не добавлять drag-and-drop в эту задачу.
- Сохранить i18n RU/EN и theme tokens.
- Не ломать текущие locks/save/editor flows.

## Не входит в задачу

- Drag-and-drop перемещение файлов между папками.
- Контекстные меню с keyboard roving focus.
- Bulk operations.
- Rename UI.

## Желаемое поведение

- Заголовок "Редактор" в workspace header убран.
- Левая панель файлов сворачивается и разворачивается.
- В текущей папке можно создать файл и подпапку.
- У папки справа есть кнопки создать файл, создать подпапку и удалить.
- У файла справа есть кнопка удалить.
- После create/delete список обновляется.

## Заметки по реализации

- Для MVP использовать native `prompt`/`confirm`.
- Создаваемый файл по умолчанию получает `.md`, если пользователь не указал расширение.
- Для delete использовать существующий `DELETE /api/vaults/{slug}/files?path=...`.

## Критерии приёмки

- UI позволяет свернуть левую панель.
- UI позволяет создать файл/папку в текущей директории и внутри папки.
- UI позволяет удалить файл/папку с подтверждением.
- Tests/build/go tests проходят.

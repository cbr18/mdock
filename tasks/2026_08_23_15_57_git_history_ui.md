## Проблема

В roadmap следующая задача — `14 Git history UI`. Сейчас UI показывает только короткий список коммитов в настройках хранилища, без changed files и diff. Пользователь не может понять, что именно изменилось в коммите.

## Доказательства

- Backend имеет только `GET /api/vaults/{slug}/git/commits`.
- Frontend `CommitList` показывает subject/author/date/hash.
- API для changed files/diff отсутствует.

## Нефункциональные ограничения

- Не реализовывать restore из коммита в этой задаче.
- Не добавлять внешние diff libraries.
- Не ломать текущие git remote/status endpoints.
- Не показывать diff для бинарных файлов как текст.
- Не менять WebDAV/file mutation behavior.

## Не входит в задачу

- Restore file from commit.
- Side-by-side визуальный diff.
- Conflict resolution.
- Git branch UI.
- Remote push automation.

## Желаемое поведение

- В backend есть API для деталей коммита: changed files и unified diff.
- В web UI есть отдельная секция истории хранилища.
- Пользователь видит список коммитов, выбирает коммит, видит changed files и diff.
- Restore action отображается как disabled/later, если нужен placeholder.
- UI переведён на ru/en.

## Заметки по реализации

- Minimal API: `GET /api/vaults/{slug}/git/commits/{hash}`.
- Response: commit metadata, `files`, `diff`.
- Changed files через `git show --name-status --format=...`.
- Unified diff через `git show --format= --patch --binary=false --find-renames <hash>`.
- Hash валидировать как hex prefix/full hash, чтобы не дать argument injection.
